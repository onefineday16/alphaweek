# AlphaWeek Personal Research Desk — รุ่นทดลองบนเครื่อง

> ชุดทดลองนี้แยกจากเว็บ AlphaWeek Production ที่อยู่ใน root ของ repository และต้องรันบนเครื่องด้วย Python 3. ยังไม่ใช่ Vercel deployment

ผู้ช่วยค้นและคัดกรองหุ้นไทยสำหรับคนที่ไม่มีเวลารวบรวมข้อมูลเอง ค้นหุ้นสามัญใน SET/mai แล้วสรุปราคาสาธารณะ แนวโน้มสั้น ข่าวที่พบ หลักฐานค้าน เงื่อนไขก่อนพิจารณาซื้อ และข้อมูลที่ยังขาด จากนั้นเก็บผลไว้กลับมาตรวจซ้ำหรือเปรียบเทียบได้สูงสุด 3 ตัว

รุ่นนี้ใช้กฎที่ตรวจสอบได้บน Python standard library ไม่มี LLM ไม่มีค่าบริการ AI ไม่มีการเชื่อมบัญชีโบรกเกอร์ และไม่มีคำสั่งซื้อขายอัตโนมัติ ผลลัพธ์เป็นแฟ้มวิจัยเบื้องต้น ไม่ใช่คำแนะนำการลงทุนเฉพาะบุคคล

## เริ่มใช้งาน

1. ดับเบิลคลิก `Start-Radar.cmd` แล้วเปิดหน้าต่างโปรแกรมไว้
2. เปิด <http://127.0.0.1:8787> บนเครื่องนี้
3. ไปที่ **ค้นและวิเคราะห์** พิมพ์ชื่อย่อ เช่น `AOT`, `PTT`, `KBANK` หรือชื่อบริษัทภาษาอังกฤษ
4. กด **วิเคราะห์หุ้นนี้** ระบบจะดึงราคา กราฟระยะสั้น และเชื่อมข่าว RSS ที่เก็บไว้
5. อ่าน **หลักฐานที่ใช้**, **หลักฐานค้าน**, **ข้อมูลที่ยังขาด** และลิงก์ SET/SEC ก่อนตัดสินใจเอง
6. ใช้ **ติดตาม** เพื่อกลับมาตรวจซ้ำ หรือ **เพิ่มเพื่อเทียบ** ได้สูงสุด 3 หุ้น

ถ้า Codex เปิดโปรแกรมไว้ให้ เข้า URL ได้เลย `TRIAL_ALREADY_RUNNING` หมายถึงมี Radar ใช้ข้อมูลชุดนี้อยู่แล้ว ปิดตัวเดิมก่อนสลับโหมด โปรแกรมรับเฉพาะ `127.0.0.1`/`localhost`; โทรศัพท์และเครื่องอื่นเข้าไม่ได้

## สิ่งที่เพิ่มในรุ่น 0.2

- ค้นรายชื่อหุ้นสามัญ SET/mai จาก TopTrader Public โดยไม่จำกัดแค่พจนานุกรมข่าวเดิม
- แฟ้มวิเคราะห์รายตัวพร้อมมุมมอง 4 แบบ: **น่าสนใจสำหรับศึกษาต่อ / รอข้อมูลยืนยัน / ระวัง / ข้อมูลยังไม่พอ**
- แสดงราคาล่าสุด ช่วงข้อมูลกราฟ จำนวนข่าว หลักฐานค้าน แผนตรวจต่อสำหรับคนกำลังหา และเงื่อนไขทบทวนสำหรับคนถืออยู่
- บันทึกผลล่าสุดและประวัติย่อ 10 ครั้ง พร้อมบอกว่าราคา มุมมอง หรือจำนวนข่าวเปลี่ยนจากครั้งก่อนอย่างไร
- ตารางเปรียบเทียบสูงสุด 3 ตัว และ watchlist ที่รองรับหุ้นที่ค้นเจอใหม่
- หน้าแหล่งข้อมูลบอกสถานะ เวลา และข้อจำกัดอย่างตรงไปตรงมา

## แหล่งฟรีที่ใช้

### TopTrader Public

ไม่ต้องสมัครและไม่ใช้ API key โปรแกรมเรียกเฉพาะ public GET ตาม [เอกสารผู้ให้บริการ](https://developers.toptrader.co.th/docs/):

- `/v1/market/symbols` สำหรับรายชื่อหุ้นสามัญ SET/mai แคช 24 ชั่วโมง
- `/v1/market/tick` สำหรับ last/bid/ask และเวลาที่ผู้ให้บริการระบุ
- `/v1/market/chart` สำหรับกราฟรายนาทีช่วงล่าสุด แล้วสรุปเป็นวันบนเครื่อง

ราคาที่แสดงเป็นภาพข้อมูลตามเวลาที่ API ระบุ ไม่รับรอง real-time กราฟครอบคลุมเท่าที่ผู้ให้บริการส่งมาและยังไม่ใช่ประวัติรายวันปรับ corporate actions ระบบจำกัดการวิเคราะห์ 60 ครั้งต่อวันบนเครื่องและใช้ผลเดิม 10 นาทีต่อหุ้นเพื่อลดคำขอ

### ข่าว RSS

- [InfoQuest หมวดหุ้น](https://www.infoquest.co.th/stock/feed): แสดงหัวข้อกับข้อความย่อรวมไม่เกิน 200 ตัวอักษรพร้อมลิงก์ต้นทาง
- [ThaiPR.NET หมวดการเงิน](https://www.thaipr.net/finance/feed): ข่าวประชาสัมพันธ์ ต้องตรวจประกาศบริษัทหรือหลักฐานอิสระประกอบ

เก็บข่าวสูงสุด 7 วัน/400 รายการ RSS ส่งเฉพาะรายการล่าสุดจึงไม่รับรองข่าวครบทุกวัน การเชื่อมข่าวกับหุ้นใช้ชื่อย่อที่ปรากฏในหัวข้อหรือข้อความย่อ ไม่ดึงบทความเต็มและไม่ส่งข่าวเข้า LLM

### EODHD Free — ตัวเลือกเสริม

ไม่จำเป็นสำหรับการค้นและวิเคราะห์ข้างต้น หากต้องการทดลองข้อมูล EOD และมีบัญชีฟรีของตัวเอง ให้ปิดโปรแกรมเดิม เปิด `Start-Radar-With-Prices.cmd` พิมพ์ `FREE` แล้วกรอก key ในช่องซ่อนค่าบนเครื่อง ห้ามส่ง key ในแชต ระบบไม่บันทึก key และหยุดหากยืนยันขีดจำกัดบัญชีฟรีไม่ได้

## วิธีอ่านผลวิเคราะห์

มุมมองมาจากกฎ `rules-0.2`:

- ต้องมีราคาล่าสุดและข้อมูลอย่างน้อย 2 วัน มิฉะนั้นขึ้น **ข้อมูลยังไม่พอ**
- ถ้ามีข่าวกลุ่มคำเสี่ยงและราคาไม่ยืนยันด้านบวก ขึ้น **ระวังและตรวจความเสี่ยง**
- ถ้าช่วงข้อมูลเป็นบวกอย่างน้อย 2% และข่าวเหตุการณ์ใหม่มากกว่าข่าวเสี่ยง ขึ้น **น่าสนใจสำหรับศึกษาต่อ**
- ถ้าช่วงข้อมูลลดอย่างน้อย 3% ขึ้น **รอให้แนวโน้มหยุดอ่อนตัว**; กรณีอื่นขึ้น **รอข้อมูลยืนยัน**

กฎนี้ไม่รู้กำไรจริง มูลค่าหุ้น หนี้ กระแสเงินสด corporate actions หรือพอร์ตของคุณ จึงไม่สร้างคำว่า “ซื้อ/ขายทันที” และกำหนด `actionable: false` ทุกผล คุณต้องตรวจงบล่าสุด ประกาศบริษัท ราคาเหมาะสม ขนาดเงิน และจุดยอมรับว่าคิดผิดก่อนส่งคำสั่งกับโบรกเกอร์เอง

## ข้อมูลและความเป็นส่วนตัว

`local-data/state.json` เก็บแคช รายการติดตาม และแฟ้มวิเคราะห์บนเครื่อง ไม่มีรหัสโบรกเกอร์หรือ API key โฟลเดอร์นี้ถูกกันออกจาก Git ด้วย `.gitignore` ดาวน์โหลดผลทดลองจะมีเฉพาะสถานะแหล่งข้อมูล รายการติดตาม และสรุปผลวิเคราะห์ ควรตรวจไฟล์ก่อนส่งต่อ

รุ่นนี้อยู่ใน `radar-trial/` และไม่เปลี่ยนเว็บ Vercel, Apps Script หรือ Google Sheet ที่ root ของ repository ปัญหา Refresh PIN ของ Production เป็นคนละระบบ

## ตรวจซ้ำ

- `python test_radar.py` — unit + loopback HTTP tests โดยไม่เรียกอินเทอร์เน็ต
- `python radar.py --once` — ดึงข่าวจริงหนึ่งรอบขณะเซิร์ฟเวอร์ปิด
- `python radar.py --market-once` — ดึงราคาสาธารณะชุดตัวอย่างขณะเซิร์ฟเวอร์ปิด
- `node --check public/app.js` — ตรวจ JavaScript syntax
- `node verify_client.cjs` — ตรวจ client ผ่าน HTTP/JavaScript VM ขณะเซิร์ฟเวอร์เปิด โดยไม่ render HTML; หากต้องการเก็บรายงานให้ตั้ง `ALPHAWEEK_REPORT_PATH=verification-output.json`

กฎโปรเจกต์ไม่ให้ render HTML ใน ChatGPT จึงต้องให้เจ้าของเปิดหน้าเว็บจริงเพื่อตรวจ desktop/mobile, ความอ่านง่าย และความเกี่ยวข้องของผลวิเคราะห์ การผ่าน source/HTTP tests ยังไม่ใช่หลักฐานหน้าจอ Production
